# Документация проекта

## Общее описание решения

Проект включает в себя набор функций для вычисления площади и периметра фигур: прямоугольника, треугольника, квадрата и круга. Для каждой фигуры создан отдельный файл, функции которых принимают входные данные и возвращают результат вычислений.

## Описание функций

### Прямоугольник

#### `area(a, b)`
Вычисляет площадь прямоугольника по длинам его сторон.

**Параметры:**
- `a` это длина первой стороны прямоугольника
- `b` это длина второй стороны прямоугольника

**Возвращаемое значение:**
- `result` это площадь прямоугольника

**Пример вызова:**
```python
area(4, 6) = 24
```

#### `perimeter(a, b)`
Вычисляет периметр прямоугольника по длинам его сторон.

**Параметры:**
- `a` это длина первой стороны прямоугольника
- `b` это длина второй стороны прямоугольника

**Возвращаемое значение:**
- `result` это периметр прямоугольника

**Пример вызова:**
```python
perimeter(2, 3) = 10
```

---

### Треугольник

#### `area(a, h)`
Вычисляет площадь треугольника по длине основания и высоте.

**Параметры:**
- `a` это длина основания треугольника
- `h` это высота, проведённая к основанию

**Возвращаемое значение:**
- `result` это площадь треугольника

**Пример вызова:**
```python
area(6, 4) = 12.0
```

#### `perimeter(a, b, c)`
Вычисляет периметр треугольника по длинам трёх его сторон.

**Параметры:**
- `a` это длина первой стороны треугольника
- `b` это длина второй стороны треугольника
- `c` это длина третьей стороны треугольника

**Возвращаемое значение:**
- `result` это периметр треугольника

**Пример вызова:**
```python
perimeter(3, 4, 5) = 12
```

---

### Круг

#### `area(r)`
Вычисляет площадь круга по заданному радиусу.

**Параметры:**
- `r` это радиус круга

**Возвращаемое значение:**
- `result` это площадь круга

**Пример вызова:**
```python
area(5) = 78.53981633974483
```

#### `perimeter(r)`
Вычисляет длину окружности круга по заданному радиусу.

**Параметры:**
- `r` это радиус круга

**Возвращаемое значение:**
- `result` это длина окружности

**Пример вызова:**
```python?
perimeter(9) = 56.548667764616276
```
